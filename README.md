# Agentic ML Lessons

Lessons learned from using an AI coding assistant to develop the [agentic-ml project](https://github.com/jimthompson5802/agentic-ml).

This repository collects reflections on the development process: what worked, what needed improvement, and where human judgment made a difference. The lessons link to implementation plans, repository skills, and verification records that support the observations.

Additional lessons learned will be posted as the project progresses.
